# Welcome mascot cleanup

The original welcome bitmap was 192 x 208 pixels with a magenta fringe from its source background. A built-in imagegen edit used that bitmap and its original higher-resolution waving reference to clean up the same character and pose. The final asset is assets/scholar/wave-clean-v2.webp, 768 x 832 pixels (64,888 bytes), with alpha transparency. The original artwork files remain available.

Final prompt: Preserve the character, face, waving pose, clothing, colors, proportions and transparent framing; remove chroma edge flecks, retain smooth transparent edges, and add no border, background, glow, text or new content.

The welcome SVG uses the sharper asset and retains its original sleeve-wave motion. The old low-resolution blink overlay was removed to avoid compositing a second face over the updated image.
